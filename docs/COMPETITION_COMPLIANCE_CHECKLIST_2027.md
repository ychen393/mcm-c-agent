# 2027 MCM Competition Compliance Checklist

Status: Pre-checklist template. Re-verify against the official COMAP instructions immediately before any contest use.

Official source: https://contest.comap.com/undergraduate/contests/mcm/instructions.php

## Rule snapshot
- [ ] Record official rules URL and exact page/document title.
- [ ] Record date/time checked and the downloaded rules version/hash if retained.
- [ ] Confirm current page limit and what is included/excluded.
- [ ] Confirm required formatting, anonymity, file naming and submission procedure.
- [ ] Confirm AI-tool policy, disclosure placement and reference requirements.
- [ ] Confirm whether appendices, code, data or supplementary files are allowed.
- [ ] Confirm current restrictions on outside assistance and team collaboration.

## AI use record
For every material AI-assisted activity, record:
- Provider and model identifier (if available)
- Date/time and task/workflow stage
- Purpose (brainstorming, code assistance, editing, analysis support, etc.)
- What content or output was AI-assisted
- Human verification performed and by whom
- Whether any AI-generated claim, code, formula, citation or conclusion was rejected/modified

## Evidence and authorship checks
- [ ] Every factual claim has traceable evidence or is clearly identified as an assumption.
- [ ] Every citation resolves to a real source and supports the cited claim.
- [ ] All numerical results can be regenerated from retained code/data/parameters.
- [ ] Team members understand and can explain submitted methods and conclusions.
- [ ] AI-generated text/code has been critically reviewed; no output is treated as authoritative solely because a model produced it.
- [ ] Required AI-use report is complete and consistent with the actual usage ledger.

## Knowledge corpus restrictions
- [ ] Every indexed source has a Corpus Registry entry.
- [ ] Public accessibility is not treated as proof of public-domain status.
- [ ] Full-text ingestion, excerpting, external model upload and redistribution are separately reviewed.
- [ ] Unclear-rights award papers remain metadata/link-only until approved.
- [ ] Remove or disable sources whose rights or access status changes.

## Final release gate
A human team member must verify the current official rules and approve this checklist. This template is not legal advice and does not replace COMAP instructions.
